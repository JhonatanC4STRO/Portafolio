# Portafolio de Jhonatan

Portafolio personal construido con React, Tailwind CSS y Motion. Presenta una interfaz adaptable con animaciones, proyectos, capacidades, tecnologías y contacto.

## Desarrollo local

```bash
npm install
npm run dev
```

## Comandos

- `npm run dev`: inicia el entorno local.
- `npm run build`: genera la versión de producción.
- `npm run lint`: revisa la calidad del código.
- `npm run preview`: muestra localmente la versión compilada.
